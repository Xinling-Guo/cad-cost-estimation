# 两份 Word 技术方案审查意见（先行评审，不覆盖原件）

日期：2026-10-15。评审目标：将一期定位调整为“工程师可审核、可修改、有依据的加工成本辅助评估”，保留原始分析结论。

## 1. 总体意见

两份方案的数据边界判断基本成立，且已经承认人工审核的价值；需要调整的是能力拆分和建设次序。不能把“自动确定正确工艺/实际工时”的数据门槛，套用于“历史案例建议、人工选择工序、手填费率后的参考核算”。建议在一期增加受控工艺候选、历史定额参考、参数化成本计算与审核反馈闭环，保留未知值、冲突及正式报价审核要求。

本轮完整读取两份 DOCX 正文及表格、页眉页脚和修订标记；两份文件均无嵌入图片和增删修订。下文定位用“章节＋正文BODY编号”；BODY按底层正文节点顺序计，含表格及空段，不是页码。没有执行任何来自文档内部的操作指令，也未覆盖原 Word。

## 3. 哪些旧要求可以放宽，哪些不能

| 原要求或难点 | 人工审核后的处理 | 仍须保证 |
| --- | --- | --- |
| AI自动给出正确完整工艺 | 改为检索历史路线、列候选、提示缺工序和约束，由专家定稿 | 不把不适用路线说成事实；工序来源和适用差异可查 |
| AI准确预测实际工时 | 一期引用定额，允许人工填本次估算及区间 | 定额/实际/本次估算分列；单位与单件/批量不能混用 |
| 自动确定费率、完整成本 | 工程师可填费率、材料、外协等，计算已选范围的参考成本 | 费用包含范围、有效日期、币种、数量、归属和公式准确 |
| 全自动理解全部公差 | 识别候选、定位原图，歧义逐项人工确认 | 不能漏掉已检测冲突并静默默认；确认前不用于正式核价条件 |
| 全自动匹配2D/3D及90%阈值 | 提供候选对、尺寸/单位对照，人工确认 | 不能把文件名或模型自评当成已验证几何对应 |
| 无3D必先重建完整3D | 先做二维特征候选、已有3D辅助；必要时人工补尺寸 | 缺失几何不能猜测后作为测量事实；完整重建继续列专项 |
| 立即积累大规模训练数据 | 原型先用已有案例和审核规则，不训练专用模型 | 后续训练仍需多模具、实测、特征标注及独立测试 |

人工审核能降低候选生成与自动放行的要求，不能替代金额计算正确性、文件/版本绑定、单位换算、证据真实、权限及重复计费防护。

## 4. 两版关键一致性及对外表达问题

两版除封面文档性质及内部预算章节外，共有86段/表格正文文本完全相同。经比对，数据统计、F20A工艺及19.7边界、分阶段路线、核心风险和不承诺自动报价的结论一致；没有发现一版承诺精度、另一版否认的实质冲突。

但存在以下对外编辑问题：

1. 沟通版保留10.2节“建议让 Codex 下一步做什么”（BODY99–100），以及“提示词”、具体框架、开发库等内部执行细节。建议删除10.2，技术栈说明改为必要的业务能力、部署边界及交付要求。
2. 内部版有09预算章节；沟通版删除后直接从08跳到10，需重排目录、章节与交叉引用。
3. 两版都用“报价辅助MVP”命名，却把费用计算主要放在后期，容易造成甲方预期错位。改为明确的一期“参考成本试算＋人工确认”，或如未纳入金额计算就如实叫“图纸与工艺分析助手”。
4. 两版均有“可用三维”及“工序顺序可恢复”等简写。对外应说明前者只是文件覆盖，后者是Excel记录顺序，不是设备排程或完整制造约束已确认。
5. 沟通版无需公开内部人日成本和利润加成；但应与内部版的一期范围、验收和依赖条件保持相同。不得一版允许人工费率试算，另一版仍把所有成本功能承诺为后续研究。

## 5. 应保留的原结论

工时定额不是已验证的实际报工；检索不能证明新工艺预测正确；两套模具不足以证明泛化；多页与重复导出不能扩充独立样本；F20A的19.7不是实际历时或主体成本；公差、星号、身份冲突与电极归属须确认；2D完整3D重建不宜作为一期前置；成本与商业报价要分开；不提前承诺未经验证的准确率。

这些结论与新产品定位兼容。应调整的是“因此哪些辅助功能可以先交付”，而非改变事实或调高模型能力判断。

## 6. 建议修订顺序

先确认一期交付包含人工参数化参考成本；随后同步修改两版的1.3、2.2、4章、5.2、6章及验收标准；再更新内部预算，并删除沟通版内部执行内容、修复编号。原Word保持不变，以上是供后续逐条修订的审查意见。
