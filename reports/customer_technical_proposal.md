# 模具零部件加工成本智能评估系统技术方案

**版本：V1.0｜日期：2026年10月14日｜用途：项目方案沟通**

本方案依据甲方《模具零部件加工成本评估需求说明》及已提供 CAD 样本的数据验证结果编制。方案中的系统功能和建设计划为拟建内容，已完成的数据验证单独说明；建设范围、验收指标与实施周期由双方确认。

## 1. 项目理解

### 1.1 业务目标

建设面向模具零部件的智能加工成本评估系统，支持批量输入二维 CAD 图纸及可选的三维模型，结合材料、公差、技术要求、加工工艺和历史生产数据，输出可复核的预估加工成本，辅助核价工程师提高核价效率与一致性。

系统应重点解决三个问题：批量图纸的信息整理负担、关键制造要求的漏判，以及工艺与工时估算过度依赖个人经验。

### 1.2 优先解决的业务痛点

甲方反馈的案例表明，即使零件绘图区没有变化，图框中的一般公差变更仍可能影响核价。两位小数尺寸适用公差从 ±0.002 调整为 ±0.01 后，沿用历史要求核价造成了金额偏差。

因此，系统需要同时关注零件几何、制造要求及图纸版本，尤其是一般公差、明确尺寸公差、材料、热处理、硬度与表面要求。对关键变更应提供明确提示及图纸依据，供核价人员确认。

### 1.3 输出定位

最终输出应包含零件及图纸版本、主要加工要求、建议工艺与工序、逐工序预估工时、适用费率、分项成本和合计，并列出需要人工确认的内容。

“加工成本”与对外“报价”应分别定义。材料、毛坯、准备时间、热处理、外协、检验、损耗、税费和利润是否计入，需在启动阶段统一口径。试点阶段输出作为辅助核价依据，由甲方指定人员审核。

## 2. 数据验证结果

### 2.1 已完成的验证

已对甲方提供的 7 个经转换的二维 CAD 文件开展结构与工程信息探查，结果如下。

| 验证项 | 当前结果 | 对后续建设的意义 |
| --- | --- | --- |
| 文件读取 | 7 个文件均可读取，未发现结构审计错误 | 具备开展图纸信息提取的基础 |
| 文字及尺寸 | 提取 37,600 条文字记录、3,184 个尺寸对象 | 可以继续验证尺寸、公差和技术说明的整理能力 |
| 大图组织 | 同一模型空间内识别到 195 个图框，对应 179 个不同图号 | 支持按图号组织图纸，并合并多页信息 |
| 多页完整性 | 167 个图号为单页、8 个为两页、4 个为三页；页码集合完整 | 解释了图框数量与不同图号数量的差异 |
| 材料与硬度 | 大图可读到 SKD11、RD50、HRC60、HRA89 等；六张小图均可读到 SKD61、HRC50–52 | 可为材料与加工要求关联提供依据 |
| 公差及技术说明 | 一般公差表中的 0.01、0.002 可提取，部分小图保留成型高度 ±0.005、其余 ±0.01 和粗糙度要求 | 公差识别具备进一步验证条件 |
| 原始数据保护 | 分析前后原始文件内容一致 | 验证过程未改变甲方图纸 |

文字记录中包含重复图框及尺寸文字，不代表同等数量的独立制造要求；179 个不同图号也需与甲方零件清单核对，才能确认待核价零件数量。

### 2.2 需要继续核对的内容

一般公差与技术说明的适用范围、特殊字体符号及尺寸标注与绘图尺度的关系仍需核对。大图的制造公差主要体现在图框中，不能仅依据尺寸对象中的公差设置判断是否存在公差。

部分小图注明“未注尺寸参考 3D”，这类零件需要对应的三维模型或补充尺寸资料。现有三维文件与二维图纸的身份、版本及几何对应关系尚未完成验证。

**当前判断：样本保留了可用于制造要求分析的工程信息，支持进入限定范围的辅助核价试点。现有验证尚未证明成本预测准确性，也未证明所有图纸信息在转换前后完全一致。**

## 3. 技术路线

建议采用“图纸理解—制造要求确认—工艺分析—工时评估—成本汇总—人工审核”的路线，先建立可复核的数据基础，再逐步扩大自动评估范围。

**总体流程：**

图纸与版本登记 → 零件及多页图纸整理 → 尺寸、公差与技术要求提取 → 可选三维模型核对 → 工艺与工序建议 → 分工序工时估算 → 成本汇总 → 核价人员审核。

| 环节 | 建设内容 | 业务输出 |
| --- | --- | --- |
| 图纸整理 | 识别图号、名称、版本、页码及零件区域，归并同一图号的多页图纸 | 零件图纸清单 |
| 制造要求提取 | 整理材料、一般公差、明确公差、硬度、热处理、粗糙度和技术说明 | 制造要求卡片及图纸依据 |
| 变更识别 | 对比旧新版本中的几何、图框和技术要求 | 影响核价的变更提示 |
| 二维/三维核对 | 对已有三维模型验证零件身份、版本及关键几何对应 | 对应结果及需确认项 |
| 工艺分析 | 结合甲方审核规则、设备能力及历史工艺，提出适用工艺和工序顺序 | 工艺路线建议 |
| 工时评估 | 分别评估约定范围内的 CNC、磨削、线切割及检验等工序 | 逐工序工时及依据 |
| 成本汇总 | 按确认的工时、费率、批量及成本口径计算 | 分项成本、单件成本和批量成本 |
| 审核反馈 | 对缺失、冲突和超出适用范围的情况提交人工确认 | 审核后的核价记录 |

智能助手的职责可围绕图纸理解、工艺分析、分工序工时评估和结果汇总逐步建设。关键公差、版本冲突及缺失制造条件须经过明确的确认流程，不以未经验证的推断替代图纸要求。

对缺少三维模型的零件，先评估二维资料是否足以支持选定任务；不足时补充资料或转人工。二维自动生成三维作为后续专项研究，需要独立验证，不作为 MVP 成本评估的必备前置步骤。

甲方需求中的二维/三维“匹配度 90%”应进一步定义评价方法及放行条件，再决定其在业务流程中的使用方式。

## 4. MVP 范围

MVP 定位为**限定零件类型、限定工艺范围、可由核价工程师复核的辅助评估系统**。分为图纸信息验证和成本评估验证两个连续环节。

### 4.1 首批试点选择

优先使用现有六张单零件二维图纸及其对应三维资料，核对版本和制造要求；从 179 个图号的大图中选取具有代表性、且可关联历史工艺和工时的零件补充验证。

试点须覆盖不同公差等级、材料或硬度要求，以及多页图纸。具体零件类型、工序及样本名单由双方共同确定；样本中不同模具类别的命名也需与实际试点范围核对。

### 4.2 纳入范围

| 功能 | MVP 目标 |
| --- | --- |
| 图纸导入与整理 | 批量登记选定样本，识别图号、版本并归并多页 |
| 工程信息提取 | 输出材料、尺寸、公差和技术要求，并提供原图定位依据 |
| 关键变更提示 | 在取得旧新图后，对一般公差及关键要求变化给出提示 |
| 人工确认 | 核价人员可确认、修正或补充关键字段和加工条件 |
| 限定工艺分析 | 在约定零件及工艺范围内，输出有历史依据的工艺建议 |
| 辅助成本评估 | 历史数据及费率经确认后，输出逐工序工时与成本估算 |
| 结果导出 | 导出零件分析表、变更清单、分项成本及审核记录 |

### 4.3 适用边界与验收

全品类自动核价、无人工确认的正式报价、任意二维图纸的完整三维重建，以及全面生产系统集成，列入后续扩展范围。

图纸信息验证通过后，再以可关联的历史数据开展成本验证。若历史工艺、工时或费率未满足要求，先交付图纸信息及变更核对能力，成本功能的实施条件由双方确认。

验收关注：关键字段准确性与漏检情况、公差变更提示效果、人工复核工作量、逐工序工时与成本偏差、批量处理时效，以及结果是否能回溯至图纸和计算依据。具体指标与阈值在试点启动时书面确定；使用独立验证样本评价，避免把同一零件的相邻版本重复计入效果验证。

## 5. 分阶段建设计划

| 阶段 | 主要工作 | 阶段成果 | 进入下一阶段的条件 |
| --- | --- | --- | --- |
| 一：样本验证与范围确认 | 完成图纸可读性验证；双方核对工程字段、试点名单和成本口径 | 数据可用性结论、试点范围及验收约定 | 关键规则与样本清单明确 |
| 二：图纸信息与变更核对 | 整理零件及版本，提取制造要求，验证一般公差与版本变化 | 信息提取与变更核对试点能力 | 关键字段经甲方审核，问题有明确处置方式 |
| 三：限定范围辅助核价 | 关联历史工艺、工时及费率；验证工艺建议与分项成本 | MVP 辅助核价系统及效果评估 | 成本数据可关联，独立验证达到双方约定指标 |
| 四：业务扩展与运行优化 | 扩展零件和工艺，建设智能助手协作能力，按需对接业务系统 | 更大范围的核价应用与运行规范 | MVP 效果稳定，新增范围具备数据与规则支持 |

阶段一的图纸结构探查已完成，工程语义与业务口径仍需双方核对。实施周期在试点范围、数据完整性及验收指标确定后安排；阶段交付采用逐步验收方式，便于尽早形成可用成果。

## 6. 需要甲方提供的数据

| 数据类别 | 建议提供内容 | 用途/提供时点 |
| --- | --- | --- |
| 图纸与零件身份 | 原始 DWG、可供对照的图面、零件清单、图号、版本、页码、有效状态 | 启动时提供，确认零件及多页关系 |
| 三维模型 | 对应 STP/STEP、关联图号及版本，必要的补充尺寸 | 针对依赖三维尺寸的试点零件提供 |
| 公差及制图规则 | 一般公差标准、适用范围、特殊符号含义、尺寸单位，以及技术说明与一般公差的优先级 | 制造要求验证前确认 |
| 变更案例 | 公差核价偏差案例的旧新图、变更说明、审核工艺及核价记录 | 用于重点业务场景验证 |
| 历史工艺 | 已审核工艺路线、工序顺序、设备及外协信息 | 成本试点前提供 |
| 实际生产工时 | 准备、加工、检验工时，单件/批次口径，批量，返工与停机说明 | 建立及核验工时估算依据 |
| 费率与成本规则 | 工序或设备费率、单位、币种、有效期，准备时间分摊和材料/外协等费用口径 | 成本汇总前确认 |
| 加工条件 | 材料与毛坯、热处理、检验要求、设备能力及典型加工约束 | 解释相同几何下的工艺和成本差异 |
| 人工审核基准 | 核价工程师确认的字段、工艺、工时和成本，争议记录 | 试点验证与验收 |

历史记录应尽量通过“零件号/图号＋图纸版本＋生产批次或日期”关联，并注明设备、数量及成本口径。历史报价可作为对照，但需与实际加工工时和成本区分。

甲方可先提供一批记录完整的代表性样本，用于验证数据关联和估算方法，再逐步扩大数据范围。同时建议指定核价与工艺对接人员，集中确认规则与争议样例。

## 7. 风险说明

| 风险 | 对业务的影响 | 处理方式 |
| --- | --- | --- |
| 一般公差或特殊符号解释有歧义 | 可能遗漏影响工艺及核价的要求 | 对照原始图面，确认规则范围与优先级，关键项人工审核 |
| 尺寸标注与绘图尺度不一致 | 直接按图形测量可能得到错误加工尺寸 | 综合标注、视图比例及三维资料核对，不以图形长度直接替代标称尺寸 |
| 二维尺寸不完整 | 部分零件无法仅凭二维图确定全部加工要求 | 补充对应三维或尺寸资料，明确缺失项 |
| 多页、版本或二维/三维错配 | 可能重复核价或引用旧版要求 | 按图号、版本、页码核对，冲突提交人工确认 |
| 历史数据无法准确关联或口径不一 | 工时与成本估算可能产生系统性偏差 | 先核验数据关联，分清准备、加工、检验及异常工时 |
| 设备、批量和材料条件变化 | 历史工时及成本难以直接复用 | 保留加工条件，按适用范围估算，定期更新费率和依据 |
| 样本覆盖有限或模具类别不同 | 试点效果无法代表所有零件 | 按零件类别与工艺分别评估，逐步扩展验证范围 |
| 试点结果被用于未经审核的正式报价 | 估算误差可能进入采购或结算流程 | 明确辅助核价定位，记录审核状态与适用条件 |

现阶段已验证工程信息的可读取性，尚未建立经验证的工时和成本估算能力。方案不承诺固定成本准确率或普遍节省金额；这些指标应通过双方确认的样本与实际记录验证。

图纸及生产数据按双方约定的授权和保密要求使用，数据访问、部署方式及与其他业务系统的交互范围在实施前明确。

## 8. 交付物

| 建设阶段 | 面向甲方的交付物 |
| --- | --- |
| 样本验证与范围确认 | CAD 数据可用性报告、图纸与图号清单、待补充数据清单、试点范围与验收指标说明 |
| 图纸信息与变更核对 | 零件制造要求表、公差及技术要求核对清单、多页/版本关系清单、关键变更提示及图纸依据 |
| MVP 辅助核价 | 可供试点使用的辅助评估系统、工艺建议、逐工序预估工时与分项成本、缺失或待确认项、审核及导出能力 |
| 试点验收 | 独立样本验证报告、工时/成本偏差分析、人工复核工作量评估、问题与适用边界清单 |
| 运行与扩展 | 使用说明、人员培训、双方约定的部署与运行资料、后续扩展建议；业务系统对接按另行确认的范围交付 |

每份零件评估结果应注明图号、版本、加工条件、计算依据及审核状态。缺失必要资料的零件输出补充资料或人工复核要求，不以默认值形成缺乏依据的金额。
