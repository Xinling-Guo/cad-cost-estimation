# 甲方资料与专家支持清单：按交付用途分级

日期：2026-10-15。目标：不等待完美数据启动人工辅助系统，同时不把未确认参数当成事实。当前已有CAD、两类工艺/定额和字典不重复索取。

## 1. 怎样理解“必须提供”

**项目启动立即需要的是范围负责人、资料使用/运行授权以及可用试点样本；现有样本可先使用。** 工时、费率、公差归属等“必须”是相应核算或审核功能闭环前需要确认，不代表缺其中任何一项就停掉全部解析/检索开发。

可通过甲方现场确认、工程师为本次输入，或隔离有疑义的零件来推进。人工输入须保留责任人、依据及有效范围；不能将本次估算改称历史实测。只有真实报工、跨模具泛化与变更检出效果，才必须新增历史/对照样本。

## 2. 必须提供或确认（P0）

| 编号 | 资料/专业支持 | 最小可接受内容/形式 | 谁确认、何时需要 | 暂缺时仍可做什么 |
| --- | --- | --- | --- | --- |
| M01 | 一期目标及核算范围 | 确认辅助决策、人工批准；选定模具类型、输入模板、费用包含/排除、币种及单件/批量输出 | 业务/核价负责人，启动时 | 范围未定只能做资料展示，不承诺完整核价交付 |
| M02 | 数据和模型运行授权 | 指定可访问人员、内部存储/备份位置、允许的模型/嵌入端点和部署环境；当前不授权资料外发 | 业务/IT，接入前 | 可继续现有本地只读分析，不默认调用外部模型 |
| M03 | 指定制造及核价审核负责人 | 至少一名能作工艺判断的负责人，成本口径有人确认；原型建议每周2–4h，MVP4–6h，重大争议另审 | 甲方项目负责人，启动时排期 | 软件可以开发，制造语义和试用效果无法替甲方验收 |
| M04 | 试点样本与当前有效版本 | 从现有数据选代表零件，注明当前使用图纸/工艺版本或“版本未确认”；不要把相同文件再次作为新样本 | 工艺/设计，在首批案例采用前 | 版本未确认可展示历史，但不能称当前生产依据 |
| M05 | 定额性质及时间单位 | 确认“工时定额”的来源、是否计划/审核；至少对采用的工序确认小时/分钟、单件/批次、准备/加工/等待口径 | 工艺/核价，定额参与计算前 | 仍可展示原文及来源，不能跨记录换算/比较为实际小时 |
| M06 | 本次工时和费率参数 | 工程师可现场填写本次估时/上下限、设备/人工费率、计价单位、是否含人工和有效期；不必先建完整历史费率库 | 授权核价/成本人员，参考金额计算前 | 无费率只显示工时与公式；不虚构金额 |
| M07 | 数量与材料/外协等费用口径 | 数量、毛坯/材料费用、外协/热处理/检验；允许手填本次值，或明确从本次范围排除；明确批次分摊 | 核价/成本人员，范围内金额审核前 | 可显示加工费部分小计，但不能命名为完整制造成本 |
| M08 | 关键制造要求确认规则 | 当前采用的材料、公差、字体符号、单位、技术要求优先级；先审核试点关键项，不要求一次覆盖全部图纸 | 工艺/设计，在对应工序/核价条件确认前 | 保留候选并允许编辑；关键未知继续标记，不静默默认 |
| M09 | 编号冲突及星号解释 | 确认D21A/D21AG、S33A*、M20A*；补充对应版本或明确暂不纳入核价样本 | 设计/工艺，在异常件采用前 | 隔离异常件，其他明确编号继续使用；不阻塞整个项目 |
| M10 | 电极依赖与费用归属 | F20A主体EDM2=0、两电极加工/放电归属、是否复用、数量；M24B=1=3缺EDM2是否资料缺失；可逐案审核 | 模具工艺/核价，在电极费用计入主体前 | 展示图与原始定额，按来源行计数；不自行合并费用 |
| M11 | 审核权限与结果用途 | 谁能修改/确认，哪些修改需重审，草稿/参考核价/正式报价如何区分；确定试用与对外导出模板 | 业务/核价/IT，在MVP审核上线前 | 原型单团队演示可先用简化流程，不视为生产审批 |

不必先提交全部企业费率和商业利润。可以只在内网由有权限者为试点输入必要参数，并限定参考成本范围；正式报价所需利润、税费和审批政策另设功能前置。

## 3. 建议提供（P1）

| 编号 | 建议资料 | 最小起点 | 支持的验证；不提供的边界 |
| --- | --- | --- | --- |
| S01 | 真实旧/新版公差案例及无变化对照 | 至少提供客户已反馈案例的旧新原图、版本与变更说明，再补几个代表对照 | 验证几何相同但图框公差变化；未提供不能验收该案例检出效果，基础对比工具仍可开发 |
| S02 | 初始相似案例判断 | 专家在现有库挑选可比与不可比案例，说明材料、精度、设备/工艺差异 | 评价检索排序，不要求先有大规模标签；库外件可能无适用案例 |
| S03 | 工艺选择规则与禁用条件 | 现有工艺标准、设备能力、典型材料/精度对应、阶段/先后约束及常见例外 | 提高候选质量；未给时只提供历史案例和专家编辑，不声称可生产 |
| S04 | 二维/三维对应确认 | 18组中先选代表文件，确认版次、单位、关键尺寸，提供可用的模型或查看方式 | 验证辅助3D分析；同名文件不能证明几何对应 |
| S05 | 已审核核价实例 | 少量有范围、工时/数量、费率及电极归属的分项算例，可脱敏为测试用参数 | 验证公式和交互；人工演示算例只证明计算正确，不替代实际成本预测验证 |
| S06 | 字体/图纸规范与类别补充 | 图框模板、特殊gdt符号对照、分类表末7项类别及72热处理定额的解释 | 降低误读与规则分歧；保留原文，未解释部分继续转人工 |
| S07 | 试用任务与人工基准 | 同一批任务原流程耗时、查找和漏项记录，工程师对候选采纳/修正原因 | 评价净效率与有用性；没有对照不能声称节省固定比例 |

S01对版本检测效果验收是必需的功能前置，但不是整个项目启动前置。S05对生产使用的公式验收也应落实；原型可先使用明确标为假设的构造算例。

## 4. 可后续提供（P2），以及一旦承诺相应能力就必须补的数据

| 资料 | 何时成为关键前置 | 不能用什么替代 |
| --- | --- | --- |
| 多套独立冲压/注塑模具、零件家族及不同加工条件 | 要扩充适用范围、评价跨模具推荐/预测时 | 同件多页、旧6组重复导出、增加同一件的工序行数 |
| 实际报工/设备记录、准备与运行拆分、批次/数量、返工/停机和质量 | 要预测或验证实际加工工时时 | 历史定额、工程师本次暂估、LLM生成数字 |
| 实际材料/外协/设备费用与独立成本样本 | 要验证成本估算误差或扩大自动核算范围时 | 演示费率、参考报价、利润税费混合的总价 |
| 加工特征—工序—设备—参数的专业标注、路线方案及选择理由 | 专用工艺推荐模型或复杂制造特征研究时 | 工序代码翻译、通用制造文字说明 |
| 足够完整的二维约束、经过验真的三维模型与专家对照 | 可靠2D→3D重建或精确面/特征对应时 | 图号相同、单一视图、未确认的生成模型 |
| MES/ERP字段字典、接口、权限、测试环境与数据同步规则 | 正式业务系统集成前 | 手工Excel导入成功 |
| 更高并发、现场/组织隔离、SLA及运维要求 | 多团队生产部署和运维报价前 | 原型在单机可运行 |

不设置“收到若干千条就必然能训练”的门槛。新增样本数量应根据零件家族、工艺覆盖和独立验证结果滚动确定；当前两套模具足够启动案例库，但不是泛化证明。

## 5. 人工输入与新增历史资料的边界

| 可以为本次人工补录 | 必须新增真实证据才能证明 |
| --- | --- |
| 本次选材、公差采用值、工序及设备、暂估工时、费率、数量、费用范围 | 新件工艺推荐整体可接受率、实际工时预测误差、跨模具泛化 |
| 单次电极归属及复用规则、经确认别名 | 所有电极后缀的通用含义、全部主体的历史真实成本 |
| 个案审核意见及知识规则候选 | 工程师点击确认的数据天然正确、适合训练或已具预测精度 |

每条补录注明“本次人工输入/估算”或“引用何种已审规则”，保存原值、采用值、理由、审核人、时间及适用范围。费用参数修改后重算并重新确认受影响结果。

## 6. 建议甲方配合节奏

启动会先确认M01–M04和安全运行方式，使用现有样本开展图纸/路线工作台；首轮试用前落实选定工序的M05–M10；参考成本审核前落实费用与归属；MVP验收前落实M11及代表性算例。

可先把S33A*、M20A*、D21A/D21AG等列为待核样本，不要求为了上手而改写原始编号。定额单位不能批量确认时，先展示原文，由工程师对本次采用项确认；未确认的单位不能进入计算。逐步解决真业务问题，而非先追求无缺项数据集。
